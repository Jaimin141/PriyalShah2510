# Priyal Birthday Website 🎂

A responsive React/Vite birthday microsite designed for GitHub Pages.

## 1. Install

```bash
npm install
npm run dev
```

## 2. Personalize

Open `src/App.jsx` and change:
- Friend's name
- Birthday date
- Memory cards
- Reasons
- Letter/signature

## 3. Build

```bash
npm run build
```

## 4. GitHub Pages

This project includes `.github/workflows/deploy.yml`.

Push the project to the `main` branch. In GitHub:
**Settings → Pages → Source → GitHub Actions**

For this repository the project URL will be:

`https://Jaimin141.github.io/PriyalShah2510/`

If the repository name changes, update `base` in `vite.config.js`.
